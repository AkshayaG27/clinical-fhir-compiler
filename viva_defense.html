Edge Transformer & Compiler Architecture

1. Outpatient Reality & ABDM Mandate

Indian OPD physicians examine 60–100 patients in 3 hours (2–3 minutes per consultation), recording prescriptions in dense Latin shorthand (e.g. Tab PCM 650mg BD pc x 3d). The Ayushman Bharat Digital Mission (ABDM) mandates structured HL7 FHIR R4 JSON for national health records.

2. The Token Bloat & Latency Bottleneck

Directly generating full HL7 FHIR JSON requires 350–500+ tokens per prescription (nested objects, coding URIs). On edge hardware ($L \le 64$ context limits), generating 500 tokens creates massive latency ($> 15\text{ seconds}$).

3. Chomsky Grammar Mismatch

JSON is a Context-Free Grammar (CFG) requiring a dynamic pushdown stack automaton to track recursive braces (`{ ... [ ... ] ... }`). Our Intermediate Representation (IR / DSL) is Regular (Type-3), parseable by an 11-state Deterministic Finite Automaton (DFA) in only 15–25 tokens ($>95\%$ sequence reduction).

4. Attention Variance Normalization

For independent query/key components with unit variance, the unscaled dot product has variance $\text{Var}(q \cdot k) = d_k$. Dividing by $\sqrt{d_k}$ rescales variance back to $1.0$, preventing softmax saturation and vanishing gradients: $$\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

5. RoPE Relative Displacement Invariance

2D Givens rotation matrices rotate vectors at position $m$ by angle $m\theta$: $$\langle R_{\theta, m} q, \; R_{\theta, n} k \rangle = q^T R_{\theta, m - n} k = g(q, k, m - n)$$ Guaranteeing shift invariance with zero learned parameters.

6. Circular KV-Cache Complexity

Stores historical keys and values in pre-allocated contiguous ring buffers. Per-token generation drops from quadratic $\mathcal{O}(L^2 d)$ naive recomputation to strictly linear $\mathbf{\mathcal{O}(L d)}$ vector dot products ($\sim 3.8\text{ ms}$ on CPU).

Question 1
Attention Mechanics & Variance Derivation
Why is the query-key dot product divided strictly by $\sqrt{d_k}$ in scaled dot-product attention? Provide the mathematical proof assuming independent components with zero mean and unit variance.
A
To ensure that attention weights sum to exactly $1.0$ across the sequence length dimension.
B
For independent query and key components with $\text{Var}(q_i)=\text{Var}(k_i)=1$, the unscaled dot product has variance $\text{Var}(q \cdot k) = d_k$; dividing by $\sqrt{d_k}$ restores unit variance ($1.0$), preventing softmax from saturating into near-zero gradient regions.
C
To account for floating-point underflow in FP16 tensors when running matrix multiplication on edge CPU vector registers.
D
Because $\sqrt{d_k}$ matches the spectral norm of an orthogonal Givens rotation matrix.
Examiner Solution & First-Principles Defense Verified
Whiteboard Proof: Scaled Dot-Product Attention Variance Normalization
Let $q, k \in \mathbb{R}^{d_k}$ be independent query and key vectors where each component is i.i.d. with: $$\mathbb{E}[q_i] = 0, \quad \text{Var}(q_i) = 1, \quad \mathbb{E}[k_i] = 0, \quad \text{Var}(k_i) = 1$$ The dot product is $S = q \cdot k = \sum_{i=1}^{d_k} q_i k_i$.

1. Expectation of $S$: $$\mathbb{E}[S] = \sum_{i=1}^{d_k} \mathbb{E}[q_i k_i] = \sum_{i=1}^{d_k} \mathbb{E}[q_i]\mathbb{E}[k_i] = 0$$ 2. Variance of $S$: $$\text{Var}(q_i k_i) = \mathbb{E}[(q_i k_i)^2] - (\mathbb{E}[q_i k_i])^2 = \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] - 0 = (1)(1) = 1$$ Since components are mutually independent: $$\text{Var}(S) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = \sum_{i=1}^{d_k} 1 = d_k$$ 3. The Vanishing Gradient Consequence: When $d_k = 32$ or $64$, the standard deviation is $\sigma = \sqrt{d_k} = 8$. Inputs to $\text{softmax}(z)$ take large positive/negative values. In these tails, the softmax derivative $\frac{\partial s_i}{\partial z_j} = s_i(\delta_{ij} - s_j)$ approaches $0$, causing severe gradient vanishing.

4. Rescaling: $$\text{Var}\left( \frac{q \cdot k}{\sqrt{d_k}} \right) = \frac{1}{d_k} \text{Var}(q \cdot k) = \frac{d_k}{d_k} = 1.0$$
Question 2
Positional Encoding Geometry & RoPE Derivation
Prove that Rotary Position Embedding (RoPE) preserves relative displacement invariance: $\langle R_m q, R_n k \rangle = g(q, k, m - n)$.
A
Multiplying query and key vectors by 2D Givens rotation matrices yields $R_m^T R_n = R_{n-m}$; by trigonometric angle-subtraction identities, the inner product depends strictly on relative offset $(m - n)$.
B
RoPE applies a 1D convolution across the sequence dimension whose kernel weights decay as an inverse power of $(m - n)$.
C
RoPE adds static sinusoidal vectors $p_m + p_n$ which cancel out under Euclidean $L_2$ distance.
D
RoPE projects embeddings onto a hyperbolic Poincaré ball where distance is geodesically invariant.
Examiner Solution & First-Principles Defense Verified
Whiteboard Proof: RoPE Relative Distance Invariance
For a 2D subspace of query $q$ and key $k$, RoPE defines the orthogonal Givens rotation matrix at position $m$: $$R_{\theta, m} = \begin{pmatrix} \cos(m\theta) & -\sin(m\theta) \\ \sin(m\theta) & \cos(m\theta) \end{pmatrix}$$ The inner product of rotated vectors $\tilde{q}_m = R_{\theta, m} q$ and $\tilde{k}_n = R_{\theta, n} k$ is: $$\langle \tilde{q}_m, \tilde{k}_n \rangle = \tilde{q}_m^T \tilde{k}_n = q^T R_{\theta, m}^T R_{\theta, n} k$$ Evaluating the matrix product $R_{\theta, m}^T R_{\theta, n}$: $$R_{\theta, m}^T R_{\theta, n} = \begin{pmatrix} \cos(m\theta) & \sin(m\theta) \\ -\sin(m\theta) & \cos(m\theta) \end{pmatrix} \begin{pmatrix} \cos(n\theta) & -\sin(n\theta) \\ \sin(n\theta) & \cos(n\theta) \end{pmatrix}$$ Applying trigonometric angle identities: $$\cos(m\theta)\cos(n\theta) + \sin(m\theta)\sin(n\theta) = \cos((m - n)\theta)$$ $$-\cos(m\theta)\sin(n\theta) + \sin(m\theta)\cos(n\theta) = \sin((n - m)\theta) = -\sin((m - n)\theta)$$ Therefore: $$R_{\theta, m}^T R_{\theta, n} = \begin{pmatrix} \cos((m - n)\theta) & -\sin((m - n)\theta) \\ \sin((m - n)\theta) & \cos((m - n)\theta) \end{pmatrix} = R_{\theta, m - n}$$ $$\langle \tilde{q}_m, \tilde{k}_n \rangle = q^T R_{\theta, m - n} k = g(q, k, m - n) \quad \blacksquare$$

Question 4
Edge Inference Systems Complexity & Memory Bandwidth
What is the computational step complexity of autoregressive generation with vs without a circular KV-cache, and why was RMSNorm chosen over LayerNorm for edge deployment?
A
Without cache is $O(1)$; with cache is $O(\log L)$; LayerNorm was replaced because it suffers from catastrophic rounding errors on FP32 floats.
B
Without KV-cache, generating sequence $L$ recomputes attention across all prior tokens at cost $\mathcal{O}(L^2 d)$; a circular KV-cache stores historical keys/values, reducing per-token generation to strictly $\mathcal{O}(L d)$; RMSNorm eliminates mean-centering, saving a full memory read/write pass ($\sim 7\%$ memory bandwidth).
C
Without cache is $\mathcal{O}(L^3)$; with cache is $\mathcal{O}(L)$; RMSNorm was chosen because it allows gradients to backpropagate through quantized int8 weights.
D
The circular KV-cache eliminates all matrix multiplications; RMSNorm is mathematically required to support Rotary Position Embeddings.
Examiner Solution & First-Principles Defense Verified
Whiteboard Complexity Derivation: KV-Cache
Suppose we generate a sequence of length $L$.

1. Without KV-Cache (Naive Recomputation): $$\sum_{t=1}^L \mathcal{O}(t \cdot d_{\text{model}}) = \mathcal{O}\left( \frac{L(L+1)}{2} d_{\text{model}} \right) = \mathbf{\mathcal{O}(L^2 d_{\text{model}})}$$ 2. With Circular KV-Cache: Keys and values from steps $1 \dots t-1$ reside in a contiguous ring buffer in memory. At step $t$, query $q_t$ ($1 \times d_k$) attends to the cached keys $K[:, :, :t+1, :]$ ($t \times d_k$): $$\text{Per-Step Complexity} = \mathbf{\mathcal{O}(t \cdot d_k) = \mathcal{O}(L \cdot d)}$$ Generation drops from quadratic $\mathcal{O}(L^2)$ to linear $\mathcal{O}(L)$, achieving a steady $\sim 3.8\text{ ms}$ step latency on consumer CPU.
Why RMSNorm over LayerNorm? Standard LayerNorm centers activations by subtracting the mean: $\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$. This requires two separate memory passes over the tensor in RAM. RMSNorm normalizes strictly by the root mean square: $\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}} \odot \gamma$, executing in a single memory pass and saving $\sim 7\%$ memory bandwidth on edge hardware.
Question 5
Feedforward Architecture & SwiGLU Gating Mechanics
Why did your transformer architecture replace standard ReLU / GELU feedforward networks with SwiGLU, and how is its hidden dimension $d_{\text{ffn}}$ calculated?
A
SwiGLU provides bilinear multiplicative gating $(\text{SiLU}(x W_{\text{gate}}) \otimes x W_{\text{up}}) W_{\text{down}}$, allowing dynamic feature routing; $d_{\text{ffn}}$ is scaled to $\approx \frac{8}{3} d_{\text{model}}$ (340) to maintain parameter parity with standard $4 d$ MLPs.
B
SwiGLU eliminates all matrix multiplications in the feedforward layer by replacing weights with lookup tables.
C
SwiGLU was chosen to ensure that feedforward activation values remain strictly binary (0 or 1) for the DFA logit mask.
D
Standard ReLU networks cannot be trained using the AdamW optimizer without triggering division by zero.
Examiner Solution & First-Principles Defense Verified
The Mathematical Advantage of SwiGLU (Shazeer, 2020): In a standard transformer MLP, a single projection is followed by an activation: $\text{FFN}(x) = \text{GELU}(x W_1) W_2$. In SwiGLU, the network performs a bilinear gated element-wise multiplication: $$\text{SwiGLU}(x) = \Big( \text{SiLU}(x W_{\text{gate}}) \otimes (x W_{\text{up}}) \Big) W_{\text{down}}$$ The gating branch $\text{SiLU}(x W_{\text{gate}})$ acts as a smooth, continuous "dimmer switch" that dynamically modulates feature flow into $W_{\text{down}}$, providing superior gradient propagation.
Parameter Parity Calculation
A standard MLP with hidden dimension $4 d$ has $2 \times (d \times 4d) = 8 d^2$ parameters. SwiGLU uses three matrices ($W_{\text{gate}}, W_{\text{up}}, W_{\text{down}}$), each of dimension $d \times d_{\text{ffn}}$, totaling $3 d \cdot d_{\text{ffn}}$ parameters. To maintain identical parameter capacity: $$3 d \cdot d_{\text{ffn}} \approx 8 d^2 \implies d_{\text{ffn}} \approx \frac{8}{3} d_{\text{model}}$$ For our model with $d_{\text{model}} = 128$: $$d_{\text{ffn}} = \left\lfloor \frac{8}{3} \times 128 \right\rfloor = 341 \implies 340$$
Question 6
Model Paradigm Selection: Decoder-Only vs. Encoder-Decoder
Why did your architecture adopt a Decoder-Only causal model rather than a standard Encoder-Decoder (like T5) for shorthand compilation?
A
Encoder-Decoder models divide parameter capacity between two sub-networks and require maintaining dual KV-caches (encoder cross-attention and decoder self-attention); a Decoder-Only model unifies sequence modeling into a single causal KV-cache, maximizing parameter utilization at $L \le 64$.
B
Encoder-Decoder models cannot perform backpropagation when trained using the CrossEntropyLoss loss function.
C
Decoder-Only models eliminate the need for embedding layers by converting text directly into bytecode.
D
PyTorch has deprecated Encoder-Decoder architectures in all versions after 2.0.
Examiner Solution & First-Principles Defense Verified
The Systems Advantage of Decoder-Only at the Edge: In an Encoder-Decoder architecture (e.g. T5, BART):
  • Parameters are split: A 1M parameter budget must be divided into a 500k encoder and 500k decoder. During autoregressive token generation, the encoder sits completely idle in memory, wasting 50% of the hardware memory footprint!
  • Dual KV-Cache complexity: Autoregressive decoding requires managing two distinct cache buffers: 1. An immutable cross-attention key/value matrix from the encoder ($L_{\text{enc}} \times d$). 2. A dynamic causal self-attention key/value ring buffer for the decoder ($L_{\text{dec}} \times d$).
Decoder-Only Resolution: Unifies prompt and completion into a single contiguous causal token sequence: $$[\text{Prompt Shorthand}] + [\text{SEP}] + [\text{Generated DSL}]$$ 100% of weights participate in autoregressive generation, and memory is unified into a single circular ring buffer ($128\times 64$ tensor).

A
At decoding step $t$, if the state machine is in `STATE_MED_DRUG`, logits for all vocabulary IDs outside the 50 approved NLEM formulary entities are set to $-\infty$; taking $\text{softmax}(z)$ assigns exactly $0.0$ probability to unapproved tokens.

The temperature parameter in softmax is dynamically set to 0.0001 whenever a drug name is decoded.

The tokenizer merges all 50 drug names into a single monolithic token, preventing character-by-character prediction.
Examiner Solution & First-Principles Defense Verified
Whiteboard Proof: Mathematical Zero-Probability Masking
Let $z \in \mathbb{R}^{|V|}$ denote the raw logit vector output by the language model head at decoding step $t$. Let $\mathcal{V}_{\text{NLEM}} \subset \mathcal{V}$ denote the discrete subset of valid drug token IDs (50 entities from the Indian National List of Essential Medicines 2022).

The DFA engine computes the masked logit vector $\tilde{z}$: $$\tilde{z}_i = \begin{cases} z_i & \text{if } i \in \mathcal{V}_{\text{NLEM}} \\ -\infty & \text{if } i \notin \mathcal{V}_{\text{NLEM}} \end{cases}$$ Passing through the softmax operator: $$P(x_t = i) = \frac{\exp(\tilde{z}_i)}{\sum_{j \in \mathcal{V}} \exp(\tilde{z}_j)}$$ For any unapproved or hallucinated drug token $k \notin \mathcal{V}_{\text{NLEM}}$: $$\exp(\tilde{z}_k) = \exp(-\infty) = 0 \implies P(x_t = k) = \frac{0}{\sum_{j \in \mathcal{V}_{\text{NLEM}}} \exp(z_j)} = \mathbf{0.000}$$ Mathematically eliminates hallucinated compounds from the output probability distribution prior to sampling.
Question 8
Training Protocol: Teacher Forcing vs. Free Generation
What is Teacher Forcing, why is it used during training instead of free autoregressive generation, and what artifact does it allow during GPU training?
A
Teacher Forcing feeds the true ground-truth token $x_{t-1}^*$ as input at step $t$ rather than the model's own predicted token $\hat{x}_{t-1}$; this prevents cascading errors and enables parallel training across all 64 sequence tokens via a lower-triangular causal attention mask.
B
Teacher Forcing uses a teacher neural network (like GPT-4) to distill knowledge into the smaller edge transformer.
C
Teacher Forcing forces the learning rate to remain constant throughout training, eliminating the need for cosine warmup.
D
Teacher Forcing forces all attention heads to attend strictly to the first token in the sequence.
Examiner Solution & First-Principles Defense Verified
Teacher Forcing Mechanics: In free autoregressive generation, step $t$ takes the model's generated sample $\hat{x}_{t-1}$. In early training, the model outputs random tokens; feeding an erroneous token at step 2 derails the remainder of the 64-token sequence, preventing the model from ever learning late-sequence grammar tokens (like duration or conditions).

Teacher Forcing replaces $\hat{x}_{t-1}$ with the true target token $x_{t-1}^*$ at every step. Because all inputs $x_1^*, \dots, x_{T-1}^*$ are known ahead of time:
  • The model does not need to execute sequentially in a loop of $T$ iterations during training!
  • The entire sequence $X \in \mathbb{R}^{B \times L \times d}$ is processed simultaneously in a single massive matrix multiplication using the causal lower-triangular mask ($M_{ij} = -\infty$ for $j > i$).
Question 9
Hardware Architecture & L1 Cache Residency
Why was context length fixed at $L = 64$ for the edge transformer, and what CPU cache benefit does this provide?
A
100% of outpatient encounters span $\le 54$ tokens in the DSL; at $L = 64$, the entire $64 \times 64$ float32 attention matrix occupies only $16\text{ KB}$, fitting entirely inside a modern CPU's L1 data cache (32–48 KB) and eliminating RAM bandwidth stalls.
B
PyTorch tensors are restricted to powers of two that divide evenly into 1024.
C
RoPE positional frequencies degrade into complex imaginary numbers when sequence length exceeds 64.
D
The HL7 FHIR R4 schema limits prescription JSON bundles to at most 64 bytes.
Examiner Solution & First-Principles Defense Verified
Hardware Memory Hierarchy Calculation
On modern Intel / AMD / ARM edge processors, memory hierarchy access latencies vary by orders of magnitude:
  • L1 Data Cache: $\approx 1\text{ ns}$ (32 KB – 48 KB per core).
  • L2 Cache: $\approx 3\text{–}4\text{ ns}$ (512 KB – 1 MB).
  • L3 Cache: $\approx 10\text{–}15\text{ ns}$.
  • Main System RAM (DDR4/DDR5): $\approx 60\text{–}80\text{ ns}$ (Major Bottleneck!).
At context length $L = 64$ with 4 attention heads: $$\text{Attention Matrix Size} = L \times L = 64 \times 64 = 4,096 \text{ float32 elements} = \mathbf{16,384 \text{ bytes (16 KB)}}$$ The entire attention matrix for an active head fits comfortably inside the CPU's **L1 Data Cache (32 KB)**! The CPU never has to evict cache lines to main RAM during self-attention computation, yielding sub-4 millisecond per-step CPU inference times.
